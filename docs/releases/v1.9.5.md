# KeyJaya 1.9.5

## Changes

- Insert scripture with **Left Ctrl**, including ranges such as `BG2.1-3`.
  Bare references insert verses only; `VT` pairs verses with their translations.
  Consecutive verses sharing one translation include that translation once.
- Cleaner, continuous spelling cycles retain verified alternatives and the
  original plain spelling.
- Fix Excel cell editing and browser first-word/rich-text cycling. Improve input
  queue recovery and verification after multiline scripture insertion so typing
  can continue without the previous stalls.
- Add `SSR` → `The Science of Self-Realization` and update `ACBSP` to
  `A.C. Bhaktivedanta Swami Prabhupāda`, preserving customized trigger entries.
- Repair 276 scripture identifiers. All verse and translation text is unchanged.

## Install or update

Download and run **KeyJaya-Setup-v1.9.5.exe** below. Requires Windows x64 and
.NET Framework 4.8. Existing settings and custom triggers are preserved.

The installer is unsigned. Compare its SHA-256 with **SHA256SUMS.txt** using:

```powershell
Get-FileHash .\KeyJaya-Setup-v1.9.5.exe -Algorithm SHA256
```
