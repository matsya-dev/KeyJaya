# KeyJaya 1.9.6

## Changes

- Fix Word conversions that highlighted text without replacing it when multiple
  Word instances were open. This covers Ctrl conversion, explicit triggers and
  scripture insertion.
- Preserve missing or deliberately deleted `BB` triggers on the first upgrade,
  including profiles without a migration marker. BB remains in fresh defaults
  and can be restored through an explicit trigger-editor action.
- Consolidate factory triggers and customization defaults. Existing settings,
  personal triggers and older customization files continue to work.
- Give unified replacement rules priority over matching legacy rules while
  retaining the order of unrelated replacements.
- Simplify the installed files and repair links in the offline user guide.
  Keep source archives and development records outside the installed app.
- Organize the code into documented components and add shared editor-contract
  checks and conversion-engine performance checks.

## Install or update

Download and run **KeyJaya-Setup-v1.9.6.exe** below. Requires Windows x64 and
.NET Framework 4.8. Existing settings and custom triggers are preserved.

The installer is unsigned. Compare its SHA-256 with **SHA256SUMS.txt** using:

```powershell
Get-FileHash .\KeyJaya-Setup-v1.9.6.exe -Algorithm SHA256
```

## Verification

All 44 automated suites passed, with 26,940,784 assertions and zero failures
(full run plus the final focused trigger-editor restoration checks).
The owner also confirmed conversion, cycling, undo and continued typing in
Word using Balarama, a browser, InDesign and an Excel cell in editing mode.
Warm engine benchmarks passed the 150 ms budget in all 17 cases; these measure
the conversion engine rather than end-to-end editor response time.

The installer passed payload-integrity, clean-install, edited-trigger upgrade
and exact rollback checks. Upgrade and rollback from the actual 1.9.5 installer
also passed, including preservation of custom, disabled and deleted triggers.
Native Word tests passed a three-second COM stall, focus-loss rollback, formatting
and single-step undo. A physical Ctrl conversion followed by immediate typing
also passed across the three-second stall.

See the [verification report](https://github.com/matsya-dev/KeyJaya/blob/v1.9.6/docs/VERIFICATION.md)
for results and coverage limits.
See the [user guide](https://github.com/matsya-dev/KeyJaya/blob/v1.9.6/docs/USER_GUIDE.md)
for shortcuts and configuration. These checks do not guarantee compatibility
with every editor or cover Windows sign-in and sleep/wake.
