# KeyJaya 1.9.4

The first public source and Windows installer release of KeyJaya.

KeyJaya is a Windows tray app for Sanskrit and Bengali writing. It supports
Unicode and Balarama/Legacy fonts, letter and word cycling, editable short
triggers, scripture insertion, contractions, and selective automatic italics.
Conversion tools support IAST, plain Roman text, ITRANS, Devanagari, Bengali,
and Hindi input/output. Shortcuts and triggers can be customized in the app.

## Install

Download and run **KeyJaya-Setup-v1.9.4.exe** from the assets below. Requires
Windows x64 and .NET Framework 4.8. Launch KeyJaya from the Start menu, then open
**Cheat sheet** from its tray icon for shortcuts. Upgrading preserves your edited
triggers and installed configuration.

The installer is not digitally signed. `SHA256SUMS.txt` provides its checksum;
you can compare it with `Get-FileHash .\KeyJaya-Setup-v1.9.4.exe -Algorithm SHA256`.
