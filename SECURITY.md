# Security policy

## Supported versions

Security reports are reviewed for the latest published KeyJaya release. Older
versions may require an update to receive a fix. Maintenance is best effort;
there is no guaranteed response or patch deadline.

## Report a vulnerability privately

Use [GitHub's private vulnerability report form](https://github.com/matsya-dev/KeyJaya/security/advisories/new).
Describe the affected version, impact, and steps to reproduce using disposable
test text or files. Include relevant Windows/app versions when needed.

Do not put vulnerabilities, credentials, private documents, or unredacted
clipboard contents in public issues. If the private form is unavailable, open
an issue asking for a private reporting channel without disclosing the flaw.

Ordinary missed conversions, spelling problems, or UI issues belong in the
[bug-report form](https://github.com/matsya-dev/KeyJaya/issues/new?template=bug-report.yml).
See [Privacy and local data](docs/PRIVACY.md) before sharing diagnostic material.
